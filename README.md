# IT-Portfolio
This repository showcases my hands-on projects and lab work in system administration, Active Directory management, and computer networking.
Each folder represents a key area of technical skill — from automating user management in PowerShell to configuring complex Cisco Packet Tracer topologies.

I built these projects to strengthen my understanding of enterprise IT infrastructure, network design, and system security, while simulating real-world administrative environments.

## Active Directory & Windows Server Administration
This section contains GPO configurations, file server management, and automation scripts used in Windows Server environments.

🔹 Key Projects
Active Directory Automation Script – PowerShell script for automated user creation and removal based on HR data.
Group Policy Configuration – Custom GPOs for IT, HR, and Accounting OUs implementing password policies, account lockouts, USB restrictions, and drive mapping.
File Server Management – Configured quotas, file screens, and share permissions for departmental folders.
Demo Documentation – Screenshots and notes showing working implementations in a virtualized lab.

## Cisco Networking Labs
Contains Packet Tracer labs that demonstrate foundational and intermediate networking concepts aligned with CCNA topics.

🔹 Key Projects
Fundamentals: Connecting Devices, OSI Model, Life of a Packet  
LAN Switching: VLANs, STP/Rapid STP, EtherChannel  
Routing: Static Routes, EIGRP, OSPF, Floating Static Routes  
Services & Security: DHCP, DNS, NTP, ACLs, SSH  
Monitoring & Troubleshooting: Syslog, SNMP, CDP/LLDP
